# Web assets log (task A2)

Generated by `tools/make_web_assets.py` (re-runnable from repo root; needs pillow, numpy, shapely). Outputs live in tracked `data/processed/`.

## Caveat: greyscale is a DISPLAY approximation

NISAR quick-looks are NISAR's own magenta/green colour composites. They were converted to 8-bit greyscale with Rec.601 luminance (0.299R+0.587G+0.114B). This is NOT calibrated backscatter and NOT dB; it is for display only. Pixels that were pure black (nodata border) or transparent are transparent in the output. No geographic cropping: bounds equal the KML LatLonQuad. Images were only downsized (max 1400 px wide, stepping 1200/1000/... until <= 600 KB). Bounds are `[[S,W],[N,E]]`. Scenes of 3, 4, 15, 16 Oct have no KML (HTTP 401), so their bounds are copied from the nearest later KML of the same track/frame (`bounds_inferred: true`). The footprint of a fixed frame is near-identical between passes, but this is an inference, not a measurement.

## Mandals

146 polygons, simplified (0.0005 deg, topology preserved), 4-decimal coordinates. District join uses `mandal_district_2022.csv` on the geoBoundaries name, exact match, with a duplicate-name guard: each feature now carries `shapeID` in its properties, and polygons are checked against `mandals_delta_list.csv` (joined on shapeID, `frac_inside_delta_box`). If a name occurs on more than one polygon, the district match applies only to a polygon with frac_inside_delta_box >= 0.5; the others get district null. Unique names keep the CSV match even if only partly inside the box. The script reports duplicate names and any nulled polygons.
